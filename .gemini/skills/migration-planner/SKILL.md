# Migration Planner

When asked to plan a migration:
1. Examine the current schema or API endpoints.
2. Analyze the `.NET` backend for required changes (`Domain`, `Application`, `Infrastructure`, `Api`).
3. Analyze the Vue 3 frontend for affected components or API calls.
4. Write out step-by-step instructions.
5. Create a checklist for required tests (Unit/Integration).
