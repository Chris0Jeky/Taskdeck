# PR Review Flow

1. Read the provided PR diff.
2. Check changes against `docs/GOLDEN_PRINCIPLES.md`.
3. Check `docs/STATUS.md` to see if the PR aligns with the current goals.
4. Output a strictly formatted review:
   - Summary of changes
   - Architectural/Design comments
   - Security/Performance impact
   - A final recommendation
