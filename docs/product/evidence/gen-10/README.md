# GEN-10 Navigation Evidence

Last Updated: 2026-07-13

The screenshots in this folder are generated by the focused Playwright scenario in `frontend/taskdeck-web/tests/e2e/guided-navigation.spec.ts`. They show the same new-user workspace in guided mode with the single Advanced disclosure expanded and in the unchanged workbench mode.

Generate or refresh the pair from `frontend/taskdeck-web` with:

```powershell
$env:TASKDECK_CAPTURE_GEN10_EVIDENCE = '1'
npx playwright test tests/e2e/guided-navigation.spec.ts --project=chromium --workers=1
```

The test also verifies the guided first-run default, mode-scoped navigation, command-palette reachability, settings/appearance escape hatches, and axe checks for the guided and workbench states.
