**Release candidate.** This is a pre-release of Taskdeck 0.3: it is not marked *Latest*, the
container `:latest` tag does not move, and it runs two schema migrations on first start after an
automatic pre-migration snapshot. Read `UPGRADING.md` → *v0.3.0-rc.1* before upgrading a workspace
you care about, and report anything odd on the issue tracker — that is what the RC is for.

### Accountable agents: scoped MCP keys
- New API, UI and CLI keys must name their capabilities — `read`, `propose`, `manage` — and HTTP MCP
  discovery and invocation enforce them per request; keys created before 0.3 keep Full access until
  you replace them (#1309, PR #2174).

### The Review queue stays live
- An open Review page polls its queue (paused while busy or hidden), so a proposal that finishes
  triage appears without navigating away (#2194, PR #2208); an approved-revision race no longer
  leaves the page on a stale revision.

### Honest triage degradation
- When the LLM leg of a transcript triage cannot deliver — kill switch, provider down, quota gone,
  unusable output — the capture completes with a visible degradation notice in both Inbox surfaces
  instead of silently falling back (#2192, #2202, PR #2224).
- Partial transcript dates ("the 14th", "March 3") resolve against the day the triage runs
  instead of a hallucinated year (#2193, PR #2206; a retry that crosses a UTC midnight uses the
  retry's day — #2210).

### Proposals that mean what they say
- Archive-card operations block the card with a generated reason rather than applying as a silent
  no-op (#2185, PR #2216); automatic proposal expiry respects archived boards (#2197).
- The automation planner checks board permissions before it persists a proposal (#1433, PR #2219);
  the CLI card move validates the target column's board (#2125, PR #2218).

### Small things you will notice
- Displayed keyboard shortcuts are truthful and platform-aware, from one registry (#2008, #1968,
  PR #2226); Enter creates the board in the setup dialog (#1933, PR #2222); both due-date fields
  share one native date field (#2006, PR #2225); accessible column collapse on Paper boards (#2090,
  PR #2165).

### Release lane
- Prerelease tags publish as GitHub pre-releases and never move the floating container tags
  (#2217, PR #2223).

### Known limitations in this RC
- MFA TOTP seeds are stored unencrypted in the SQLite file until #1653 lands — protect the file.
- Artefact extraction (files, PDFs, images) is not connected to any request path yet (#1429).
- Batch **approve** stops at *Approved*; applying stays per-proposal (per-proposal batch execute
  is scheduled for v0.3.0 final, #1307).
- No hosted instance yet: the install-free open beta is the v0.4 theme (#2243). Taskdeck sends no
  telemetry (`docs/TELEMETRY.md`).
