Design rules

Linux is semanticRun domain, application, API shards, frontend and primary E2E once.
Windows is compatibilityTarget launchers, paths, process, desktop, MCP and SQLite behavior; full weekly/release.
Self-hosted is not privilegedUse isolated VMs, no ordinary secrets, no host shares, one job per machine.
Protect the control planePrefer an organization runner group restricted to one trusted reusable workflow and a ruleset-required workflow outside the product PR write boundary.
Unknown means fullUnmapped paths, planner errors and CI-control changes escalate to clean hosted qualification.
Do not pay twicePR carries the proof; normal main push checks provenance and starts briefly.
Measure utilityTrack failure yield, flakes, slow tests, critical path, cost, cache utility and duplicate runs.
