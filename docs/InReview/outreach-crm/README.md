# Taskdeck Outreach CRM / “Superuser” Mode — Design Pack (2026-02-23)

This pack proposes an **ethical** way to “multiply yourself” (high-throughput networking + content + follow-ups) without fake accounts or prohibited automation.

It’s designed to slot into **Taskdeck’s existing primitives**:
- Boards / columns / cards / labels / due dates
- Automation proposals + policy engine (review-first)
- Starter Packs (board blueprints)

## What you get
- A concrete product spec (goals, non-goals, principles)
- Two implementation options:
  1) **Card-first CRM** (fastest; minimal DB changes)
  2) **Structured CRM module** (proper entities; higher effort)
- UX flows + screen list
- Guardrails and “automation boundaries”
- Integrations plan (imports from official exports, not scraping)
- Starter Pack manifest JSON for an “Outreach CRM” board blueprint
- Issue seeds for GitHub

Recommended: `docs/InReview/outreach-crm/` in your Taskdeck repo.
