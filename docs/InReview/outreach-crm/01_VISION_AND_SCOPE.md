# 01 — Vision & Scope: Outreach CRM inside Taskdeck

## Problem statement
You want the **effects** of multiple “accounts” (consistent engagement, timely follow-ups, good messaging, visible shipping) but:
- you cannot (and should not) use fake profiles or automated engagement on platforms,
- you don’t want to spend mental energy remembering who to message and when,
- you want a system that turns networking/content into *manageable tasks*.

So we build: **Outreach CRM (“OutreachOps”)** — a lightweight PRM/CRM mode inside Taskdeck that:

- tracks contacts + context
- schedules follow-ups via due dates and cadences
- drafts messages/comments via AI *as proposals* (copy/paste, never auto-send)
- provides a daily “action budget” dashboard (what matters today)
- creates a measurable weekly loop (DMs sent, replies, calls booked, referrals asked)

## Core idea
**Single account, high throughput.**
You get “multiplication” by reducing overhead:
- less time deciding what to do,
- less time writing from scratch,
- fewer missed follow-ups,
- more consistent shipping → more consistent visibility.

## Non-goals (explicit)
- No scraping LinkedIn feeds, no auto-liking/commenting, no auto-DM sending
- No fake accounts, no engagement pods, no algorithm manipulation
- No “growth hacking” that risks bans

## Principles
1) **Local-first**: contact data is sensitive → keep it local by default
2) **Review-first automation**: AI proposes; human approves and executes
3) **Low-friction capture**: quickest path from “thought” → “task/record”
4) **Deterministic cadences**: scheduling rules must be predictable/testable
5) **Guardrails**: budgets, cool-downs, and rate limits prevent spam behavior

## “Superuser” definition (what success looks like)
In 10–15 minutes/day you can:
- see the top 3–5 outreach actions for today
- send 1–3 high-quality messages
- log outcomes with 1 keystroke
- schedule the next follow-up automatically
- ship 2 posts/week without inventing from scratch

## MVP outcomes
- You never forget follow-ups.
- You always know the next action for each important contact.
- You can run a 4-week campaign (job hunt or beta users) with a scoreboard.
