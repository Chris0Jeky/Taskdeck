# 01 - Vision and Scope: Outreach CRM inside Taskdeck

## Problem statement
You want the effects of disciplined multi-account outreach (consistent engagement, timely follow-ups, quality messaging, visible shipping) while operating as a single user.

Current pain points:
- high memory overhead for who to message and when
- fragmented notes across tools and channels
- inconsistent follow-through on outreach campaigns

So we build: Outreach CRM (OutreachOps) - a lightweight PRM/CRM mode inside Taskdeck that:
- tracks contacts and context
- schedules follow-ups via due dates and cadences
- drafts messages/comments via AI as proposals
- provides a daily action budget dashboard (what matters today)
- creates a measurable weekly loop (DMs sent, replies, calls booked, referrals asked)

## Core idea
Single account, high throughput.
You get multiplication by reducing overhead:
- less time deciding what to do
- less time writing from scratch
- fewer missed follow-ups
- more consistent shipping -> more consistent visibility

## MVP scope boundaries
- No direct platform-send connectors in the initial slice (draft generation + copy path only)
- No browser-driven feed automation in the initial slice
- No account-simulation features in product scope

## Principles
1) Local-first: contact data is sensitive; keep it local by default.
2) Review-first automation: AI proposes; human approves and executes.
3) Low-friction capture: shortest path from thought -> task/record.
4) Deterministic cadences: scheduling rules must be predictable and testable.
5) Throughput controls: budgets, cool-downs, and rate limits keep operations stable.

## Superuser definition (what success looks like)
In 10-15 minutes/day you can:
- see the top 3-5 outreach actions for today
- send 1-3 high-quality messages
- log outcomes with 1 keystroke
- schedule the next follow-up automatically
- ship 2 posts/week without inventing from scratch

## MVP outcomes
- You do not miss follow-ups.
- You always have a next action for each key contact.
- You can run a 4-week campaign (job hunt or beta users) with a scoreboard.
