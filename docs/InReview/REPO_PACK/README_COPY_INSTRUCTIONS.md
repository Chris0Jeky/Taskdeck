# Copy Instructions — Repo Pack

## What is in this folder
`REPO_PACK/` is structured to be copied into your Taskdeck repository root.

It contains:
- `docs/analysis/2026-02-21_capture-automation_realignment_pack/` — planning pack
- optional `.github/ISSUE_TEMPLATE/feature.yml` — issue template (Priority defaults to V; you must update priority label manually)

## How to apply
From your local Taskdeck repo root:

1) Copy docs pack:
- copy `REPO_PACK/docs/analysis/2026-02-21_capture-automation_realignment_pack/`
  into `docs/analysis/` in your repo.

2) Optional: copy issue template:
- copy `REPO_PACK/.github/ISSUE_TEMPLATE/feature.yml` into `.github/ISSUE_TEMPLATE/`

3) Optional: reference the pack from `docs/analysis/` by adding a short bullet in an existing analysis follow-through issue or notes.

## Governance reminder
Do not add new root docs in `docs/` unless you will maintain them.
Treat this pack as a working note until you promote key decisions into:
- `docs/STATUS.md`
- `docs/IMPLEMENTATION_MASTERPLAN.md`
- checklists
