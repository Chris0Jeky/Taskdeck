# Promotion Checklist — Frontend UI Wave
Date: 2026-02-23

After shipping any UI wave slice, update canonical docs to prevent drift.

## Required
- `docs/STATUS.md`: mention new UI foundations (tokens/themes/primitives)
- `docs/IMPLEMENTATION_MASTERPLAN.md`: record completed UI issues and next sequencing
- `docs/MANUAL_TEST_CHECKLIST.md`: add/update keyboard & focus scripts
- `docs/TESTING_GUIDE.md`: include new lint/visual test commands

## Recommended
- Add screenshots/GIFs to `README` once the UI is a selling point
- Add a “Design System” section (only if you will maintain it)

## Evidence in PR
- screenshots (light/dark)
- keyboard-only verification notes
- performance notes if you touched DnD or large lists
